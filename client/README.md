# BEL-APP – клиент

React + Vite фронтенд на BEL-APP.

## Стартиране

```bash
npm install
npm run dev
```

Приложението се отваря на http://localhost:5173. Заявките към `/api` се препращат към бекенда на http://localhost:4000.

## Скриптове

- `npm run dev` – сървър за разработка
- `npm run build` – production build
- `npm run preview` – преглед на build-а
- `npm run lint` – проверка на кода
